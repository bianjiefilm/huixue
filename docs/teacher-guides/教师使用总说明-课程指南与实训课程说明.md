# 慧学 教师使用总说明

## 1. 这份说明解决什么问题

本批交付材料面向学校任课老师使用，既包含课程层面的课堂组织说明，也包含实训课程的操作和提交说明。老师可以先阅读本总说明，明确每类文档的用途，再按课程名称打开对应的教师上课指南。

本批材料覆盖课程指南和实训课程指南两类内容。实训课程不只包含 BI，也包含编程、数据处理、机器学习、深度学习、计算机视觉和大数据等方向；在本说明中统一称为“实训课程”。

## 2. 两类指南怎么理解

| 类型 | 主要解决的问题 | 老师什么时候看 |
|---|---|---|
| 课程指南 | 本节课教什么、课堂怎么组织、学生要交付什么、老师怎么查看成绩和学情 | 课前备课、安排课堂流程、课后查看学习情况 |
| 实训课程指南 | 学生如何进入实训课程、如何完成平台任务、如何提交作业或查看评测结果 | 课堂演示、学生实操、处理提交失败、任务打不开或评测失败 |

多数教师上课指南会把这两类信息合在同一份文档中：前半部分帮助老师理解课程目标和课堂安排，后半部分帮助老师带学生完成实训课程、提交、评分、评测和学情查看。

## 3. 老师建议使用顺序

1. 先看本总说明，确认要上的是哪一门课程或实训课程。
2. 再打开对应的 `V01-V18` 教师上课指南。
3. 课前重点看“课程总览”和“课堂入口”。
4. 上课时重点看“项目实训”“代码评测”“学生视角”等操作章节。
5. 课后重点看“教学管理”“成绩统计”“学情分析”和“排错与求助”。

## 5. 交付和分发建议

建议学校按以下方式分发：

- 发给任课老师：本总说明 + 对应课程的教师上课指南。
- 发给教研负责人：本总说明 + 全部 V01-V18 教师上课指南。
- 发给信息中心或平台管理员：本总说明 + 需要协助排错的对应指南。

学生演示账号、教师账号、平台地址等敏感或易变化信息，以学校正式交付清单为准。教师指南正文只说明使用路径和课堂操作，不建议把账号密码散落在单个课程文件中。
