# 慧学 教师指南通用部分

本文件适用于后续教师上课指南。各课程指南只写课程特异内容；平台登录、账号、运维和通用排错统一引用本文件。

## 1. 平台登录与账号

学校内网访问地址为 `http://192.168.109.42:3000`。系统访问、服务器和管理员账号信息以 [学校交付文档-慧学平台.md](../学校交付文档-Tempo%20Talents平台.md) 第 2 章为准。

教师上课前先完成三项检查：

1. 使用学校分配的教师或管理员账号登录平台。
2. 进入“我的课堂”，确认本节课对应课堂存在。
3. 使用演示学生账号进入课堂，确认学生视角能看到课程入口。

账号问题由学校信息中心优先处理。若学生登录不上，老师先确认账号、密码和学校内网地址；若需要重置密码，交给学校管理员或信息中心。

## 2. 平台运维常识

常见运维操作以 [学校交付文档-慧学平台.md](../学校交付文档-Tempo%20Talents平台.md) 第 5 章为准，包括修改 `school_admin` 密码、批量创建老师/学生账号、修改 classroom 教师、重启服务、备份和恢复。

老师日常上课不直接操作数据库和容器。遇到下列情况，先截图并交给信息中心：

| 场景 | 老师先做什么 | 信息中心处理方向 |
|---|---|---|
| 学生看不到课堂 | 确认课堂名称和学生账号 | 检查学生是否加入对应 classroom |
| 页面提示未授权 | 退出后重新登录，必要时换浏览器 | 检查账号状态和浏览器缓存 |
| 课程入口缺失 | 截图课堂详情页 | 检查 classroom 课程挂载 |
| 提交或评分失败 | 截图错误提示和时间点 | 检查前端、后端和数据库日志 |

## 3. 通用排错求助流程

老师反馈问题时，请固定提供四项信息：

1. 课堂 ID 和课堂名称。
2. training_id 或 practice_id。
3. 发生问题的账号名和角色：老师或学生。
4. 页面截图、浏览器错误提示和大致时间。

课堂内问题按优先级处理：

| 问题类型 | 优先处理人 | 说明 |
|---|---|---|
| 账号、密码、网络访问 | 学校信息中心 | 先排除账号和校园网问题 |
| 学生未加入课堂 | 学校管理员 | 检查学生是否已加入课堂 |
| 课程资源打不开 | 信息中心 + 慧学 团队 | 提供课程 ID 和截图 |
| 提交、评分、导出异常 | 慧学 团队 | 提供网络请求或错误提示 |

## 4. 联系方式

开发团队、学校侧联系人以 [学校交付文档-慧学平台.md](../学校交付文档-Tempo%20Talents平台.md) 第 7 章为准。正式手机号、邮箱、企业微信或飞书联系方式不在仓库文档中固化，由交付双方在线下或正式交付单中补充。
