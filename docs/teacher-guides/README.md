# 慧学 教师指南目录

本目录收纳 慧学 交付给任课老师使用的课堂指南。老师上课前先阅读 [00-common.md](00-common.md)，再打开对应课程指南；课程指南只保留本课特异的课堂入口、教学流程、学生视角、教学管理和排错说明。

## 使用顺序

| 步骤 | 文档 | 适用场景 |
|---|---|---|
| 1 | [通用部分](00-common.md) | 登录、账号、内网地址、排错求助和运维边界 |
| 2 | 对应课程指南 | 课前备课、课堂演示、学生提交、成绩与学情查看 |
| 3 | 第 6 章排错表 | 学生看不到课堂、任务打不开、提交失败、导出失败 |

## 维护规范

- 文档品牌统一使用 慧学。
- 课堂 ID、training_id、practice_id、task_id、演示账号和核验数据必须来自学校真实环境证据。
- 截图文件保持相对路径可访问；移动 Markdown 文件时同步检查图片链接。
- 教师手册不写平台运维敏感命令，运维动作统一指向通用部分和正式交付文档。
