### 5.1 机器指纹算法

```python
# 采集以下硬件信息生成唯一指纹
fingerprint_sources = {
    "cpu_id":      "处理器序列号",
    "board_sn":    "主板序列号",
    "mac_addr":    "主网卡MAC地址",
    "disk_sn":     "系统盘序列号",
    "memory_sn":   "内存条序列号"

# 生成指纹: SHA256(cpu_id + board_sn + mac_addr + disk_sn)
```

## 六、验证服务器设计

### 6.1 API 设计

```
授权服务器 API
├── POST /api/v1/license/activate      # 首次激活
│   Request:  {auth_code, fingerprint}
│   Response: {license_file, expires_at}
│
├── POST /api/v1/license/heartbeat     # 心跳验证
│   Request:  {license_id, fingerprint, stats}
│   Response: {status, message, next_check}
│
├── POST /api/v1/license/refresh       # 续期
│   Request:  {license_id, renewal_code}
│   Response: {new_license_file}
│
├── POST /api/v1/license/revoke        # 吊销 (管理端)
│   Request:  {license_id, reason}
│   Response: {success}
│
└── GET  /api/v1/admin/dashboard       # 管理面板
    Response: {active_licenses, usage_stats, ...}
```

### 6.2 验证服务器技术选型

| 组件 | 推荐方案 | 说明 |
|------|----------|------|
| 框架 | FastAPI / Go Gin | 轻量高性能 |
| 数据库 | PostgreSQL | 存储License记录 |
| 缓存 | Redis | 心跳状态缓存 |
| 部署 | 阿里云/腾讯云 | 可靠性保证 |
| SSL | Let's Encrypt | HTTPS加密通信 |

## 七、降级与容错策略

### 7.1 离线容忍度

| 授权状态 | 系统行为 |
|----------|----------|
| 正常 (在线验证通过) | 全功能可用 |
| 离线 1-7 天 | 全功能可用 + 顶部警告条 |
| 离线 7-30 天 | 只读模式（禁止新增/修改） |
| 离线 >30 天 / 被吊销 | 系统锁定，显示联系信息 |
| License过期 | 7天宽限期后进入只读模式 |

### 7.2 防破解措施

| 攻击方式 | 防护措施 |
|----------|----------|
| 修改系统时间 | NTP强制同步 + 服务器时间校验 |
| 复制虚拟机 | 机器指纹包含硬件序列号 |
| 修改License文件 | RSA-2048签名验证 |
| 网络拦截伪造响应 | HTTPS + 响应签名 |
| 反编译后端代码 | Nuitka编译 + 代码混淆 |
| 提取课程资源 | AES-256加密 + 密钥绑定License |

### A.3 RSA 密钥生成

```bash
# 生成私钥 (保密)
openssl genrsa -out private_key.pem 2048

# 生成公钥 (分发)
openssl rsa -in private_key.pem -pubout -out public_key.pem
```

### A.4 AES 资源加密示例

```python
from cryptography.fernet import Fernet

# 生成密钥
key = Fernet.generate_key()

# 加密文件
def encrypt_file(input_path, output_path, key):
    f = Fernet(key)
    with open(input_path, 'rb') as file:
        encrypted = f.encrypt(file.read())
    with open(output_path, 'wb') as file:
        file.write(encrypted)
```
