## 2. 前提条件

### 2.1 服务器要求

| 服务器 | 配置 | 角色 |
|--------|------|------|
| 节点一 | 24核/128GB/30TB | 管理节点 + 存储 |
| 节点二 | 40核/188GB/1TB | 工作节点 + 计算 |
| 节点三 | 32核/128GB/1TB | 工作节点 + Web |

### 2.2 软件要求

```bash
# 所有服务器需要安装
- Docker Engine 20.10+
- Docker Compose 2.0+
- SSH 服务
- Git
```

### 2.3 网络要求

- 三台服务器之间内网互通
- 节点一开放 5000 端口（镜像仓库）
- 节点三开放 3000 端口（Web访问）

## 3. 部署步骤

### 3.1 准备部署包

在本地机器上：

```bash
# 1. 克隆或拷贝项目到本地
cd ~/Work/huixue-yuanban

# 2. 进入部署目录
cd deploy

# 3. 设置执行权限
chmod +x scripts/*.sh

# 4. 配置环境变量
cp config/env.example .env
# 编辑 .env 文件，修改密码和密钥
```

### 3.2 复制到服务器

```bash
# 复制到三台服务器
scp -r deploy.tar.gz root@<慧学内网物理IP-1>:/opt/
scp -r deploy.tar.gz root@<慧学内网物理IP-2备>:/opt/
scp -r deploy.tar.gz root@<慧学内网物理IP-3备>:/opt/

# 或使用 rsync
rsync -avz --exclude='.git' deploy/ root@<慧学内网物理IP-1>:/opt/deploy/
rsync -avz --exclude='.git' deploy/ root@<慧学内网物理IP-2备>:/opt/deploy/
rsync -avz --exclude='.git' deploy/ root@<慧学内网物理IP-3备>:/opt/deploy/
```

### 3.3 初始化集群（在管理节点执行）

SSH 到节点一（<慧学内网物理IP-1>）：

```bash
# SSH 连接到节点一
ssh root@<慧学内网物理IP-1>

# 进入部署目录
cd /opt/deploy/scripts

# 初始化集群
./deploy-remote.sh init
```

输出示例：
```
[INFO] 初始化 Docker Swarm 集群...
[INFO] 在 <慧学内网物理IP-1> 上初始化 Swarm...
=== 节点加入命令 ===

在节点二 (<慧学内网物理IP-2备>) 上执行：
  docker swarm join --token xxxxxx <慧学内网物理IP-1>:2377

在节点三 (<慧学内网物理IP-3备>) 上执行：
  docker swarm join --token xxxxxx <慧学内网物理IP-1>:2377

[INFO] 尝试自动将节点二加入集群...
[OK] 集群初始化完成

[INFO] 节点状态：
ID                            HOSTNAME             STATUS    AVAILABILITY   MANAGER STATUS   ENGINE VERSION
xxxxx *                       bigdata-platform     Ready     Active         Leader           20.10.21
xxxxx                          dashujuyingyong      Ready     Active                          20.10.21
xxxxx                          huixuedashuju        Ready     Active                          20.10.21
```

### 3.4 构建镜像

```bash
# 在节点一执行
./deploy-remote.sh build
```

### 3.5 部署服务

```bash
# 在节点一执行
./deploy-remote.sh deploy
```

或使用完整部署命令：

```bash
# 一键完成所有步骤
./deploy-remote.sh start
```

## 5. 日常运维

### 5.1 重启服务

```bash
# 重启所有服务
./deploy-remote.sh restart

# 重启特定服��
./deploy-remote.sh restart backend
./deploy-remote.sh restart frontend
./deploy-remote.sh restart jupyter
```

### 5.2 扩缩容

```bash
# 后端扩展到3副本
./deploy-remote.sh scale backend 3

# Jupyter 扩展到2副本
./deploy-remote.sh scale jupyter 2
```

### 5.3 停止服务

```bash
./deploy-remote.sh stop
```

### 5.4 更新镜像

```bash
# 1. 重新构建镜像
./deploy-remote.sh build

# 2. 重启服务
./deploy-remote.sh restart
```

## 6. 故障排查

### 6.1 服务无法启动

```bash
# 检查服务日志
./deploy-remote.sh logs backend

# 检查容器状态
docker stack ps huixue
```

### 6.2 节点离线

```bash
# 查看节点状态
./deploy-remote.sh nodes

# 重新加入离线节点
# 在离线节点执行：
docker swarm leave --force
docker swarm join --token <token> <慧学内网物理IP-1>:2377
```

### 6.3 镜像拉取失败

```bash
# 检查镜像仓库
curl http://<慧学内网物理IP-1>:5000/v2/_catalog

# 重新推送镜像
./deploy-remote.sh build
```

### 6.4 端口被占用

```bash
# 查看端口占用
netstat -tlnp | grep -E '3000|8000|8888'
```

## 常用命令速查

```bash
# 查看服务状态
docker stack services huixue

# 查看所有容器
docker stack ps huixue

# 查看服务日志
docker service logs huixue_backend

# 进入容器调试
docker exec -it $(docker ps --filter name=huixue_backend -q | head -1) /bin/bash

# 重启 Docker（慎用）
systemctl restart docker

# 查看 Docker 日志
journalctl -u docker -f
```
